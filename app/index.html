Collect your own report

In a source checkout with Python 3.10+, run a read-only public GitHub collection:

python3 gapcue.py collect --issue OWNER/REPO#123 --out artifacts/research

Open the generated report.json here. Public mode uses GitHub's anonymous rate limit; --backend gh can reuse your GitHub CLI login.

Collection details

This is a bounded, non-atomic snapshot. Comments can be omitted and excerpts shortened. Handles and Stars are not demand votes. A mentioned or merged PR does not establish a released fix.

Preview v0.1.0. Source text is displayed as data. No model calls or report uploads.
